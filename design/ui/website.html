The difference

Most Markdown apps strip this. Inlay runs it.

A <script> that draws a chart, an inline SVG diagram, a <style> block or a slider widget runs as it would on a web page, in an isolated view that cannot reach your Mac or the network.

What ships in v1

An editor that respects the page and the file.

Full rendering of embedded content

Raw HTML, inline and linked SVG, document-level styles and scripts run at page level in the Read view. No iframes, no sanitizer surprises.

Offline charts

Chart.js, ECharts, D3, Mermaid and KaTeX URLs on cdnjs, jsDelivr and unpkg are swapped for bundled copies. Your report renders on a plane.

WYSIWYG with raw islands

Write in a rich editor. Anything that cannot round-trip losslessly, such as raw HTML, front matter or comments, becomes an island with its own in-place source editor.

Source and Split modes

CodeMirror 6 for the whole file when you want it. Split shows the source beside the live Read view with scroll sync.

The file on disk is sacred

Open and save without edits: byte-identical. Edit one block: only that block's bytes change, line endings and BOM included.

Security model

Running your document's JavaScript is the point. So the view is locked down.

  • Each document gets its own web view with a non-persistent data store and no bridge to native code.
  • A Content Security Policy blocks fetch, XHR and WebSockets. A per-document “Allow network” toggle relaxes it for files you trust.
  • The app serves only files in the document's folder and resolves every path to block traversal.
  • Downloaded files open with scripts off until you choose “Trust this document”. Inlay never modifies the file to remember that.

Quick Look

Press Space. See the real document.

The Quick Look extension renders through the same parser as the app, running in JavaScriptCore with no web view. Inline SVG always renders; scripts stay off unless you opt in; everything else falls back to a clean static page.
